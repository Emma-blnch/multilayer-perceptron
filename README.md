# multilayer-perceptron

42 project: implement a multilayer perceptron from scratch to classify breast
cancer tumors (malignant/benign) from the Wisconsin Diagnostic Breast Cancer
(WDBC) dataset. See `en.subject.pdf` for the full subject.

## Setup

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Project structure

```
scripts/
  split_data.py        # 1. mandatory: splits data_clean.csv into train/valid
  train.py              # 2. mandatory: trains the MLP on the split dataset
  predict.py            # 3. mandatory: loads a trained model and predicts
  core/
    network.py          # layer definitions + weight initialization
    preprocessing.py    # csv loading, one-hot encoding, normalization
  tools/
    clean_data.py       # raw data.csv -> headers + sanity checks -> data_clean.csv
    explore_data.py     # EDA: summary stats + graphs, before training anything
clean_generated.sh      # removes the files generated by split_data.py/train.py
```

`split_data.py`, `train.py` and `predict.py` are the 3 mandatory programs
required by the subject. `core/` holds the code they share (network, data
prep) and is not meant to be run directly. `tools/` holds the exploratory
scripts used before/around training, not part of the mandatory pipeline.

## Usage

Clean the raw dataset (adds headers, sanity-checks values, writes
`data/data_clean.csv`):

```sh
python scripts/tools/clean_data.py [data/data.csv] [data/data_clean.csv]
```

Explore the cleaned dataset (prints a summary, saves graphs to `outputs/`):

```sh
python scripts/tools/explore_data.py [data/data_clean.csv] [--outdir outputs/]
```

Split the cleaned dataset into a training set and a validation set
(stratified by diagnosis, `--seed` for a repeatable split):

```sh
python scripts/split_data.py [data/data_clean.csv] [--ratio 0.8] [--seed 42]
```

Train the network on the split dataset (writes the normalization stats to
`data/normalization.json`):

```sh
python scripts/train.py [--train data/data_train.csv] [--valid data/data_valid.csv] \
    [--hidden-layers 24 24] [--activation sigmoid] [--seed 42]
```

Remove the files generated by `split_data.py`/`train.py`
(`data/data_train.csv`, `data/data_valid.csv`, `data/normalization.json`):

```sh
./clean_generated.sh
```
